  1. 01CazumbáTriagem de fraudes em movimentações de rebanho+−

    problema

    Auditar à mão as 5,2 milhões de movimentações de rebanho do SIGAMA era inviável.

    construí

    Fiz uma API em Node.js/TypeScript integrada ao SIGAMA, com Gaussian Mixture Model e LLM local, e um painel em React num servidor dedicado que configurei.

    resultado

    Os técnicos recebem ranking de risco por registro e relatório de cada caso suspeito, e o modelo já pegou um esquema de lavagem de animais com até 200 cabeças movimentadas num dia.

    • Node.js
    • TypeScript
    • React
    • Prisma ORM
    • Gaussian Mixture Model
    • LLM local
  2. 02BarkBookCarteira de saúde de pets+−

    problema

    Tutores perdem a data da próxima vacina e não têm como mostrar a carteira do pet sem entregar a conta.

    construí

  3. 03Fraudes em licitações (Op. Patrola)Anéis de conluio entre fornecedores+−

    problema

    Achar conluio entre fornecedores nas compras de máquinas pesadas do dataset da Operação Patrola.

    construí

    Fiz a camada de NLP com embeddings LegalBert-pt, grafos k-NN no FAISS, comunidades Leiden e Qwen2.5 local via Ollama, em infraestrutura própria por causa dos dados sensíveis.

    resultado

    O pipeline aponta os anéis de conluio e o trabalho foi defendido e aprovado em jul./2026.

    • Python
    • LegalBert-pt
    • FAISS
    • Leiden
    • Ollama
    • Qwen2.5
    repo →
  4. 04NeuroscapeTendências em 20 mil artigos científicos+−

    problema

    Um projeto acadêmico internacional que processa 20 mil artigos com LLMs dependia das APIs pagas da OpenAI e da VoyageAI.

    construí

    Migrei para Ollama, LangChain e embeddings MIReAD e criei uma inferência por etapas que roda Qwen2.5 e Gemma em máquinas sem GPU dedicada, tudo em Docker.

    resultado

    O projeto deixou de depender de APIs comerciais, e o MIReAD aderiu melhor aos dados que o Voyage.

    • Python
    • Ollama
    • LangChain
    • MIReAD
    • Qwen2.5
    • Gemma
    • Docker
    repo →
